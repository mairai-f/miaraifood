
# HappyCash — Landing Page de Vendas

## Objetivo
Criar uma landing page profissional para vender assinaturas do sistema HappyCash - Sistema de Cobranças/PDV.

## Estrutura da Página

### 1. Header
- Logo HappyCash (imagem enviada)
- Menu: Funcionalidades | Planos | Contato
- Botão CTA "Começar Agora"

### 2. Hero Section
- Título impactante: "Controle total do seu negócio na palma da mão"
- Subtítulo explicando que é um sistema de PDV + caderneta de fiado digital
- Botão CTA principal
- Mockup/screenshots do sistema (usando as imagens enviadas)

### 3. Funcionalidades
Cards destacando cada recurso com ícones:
- 📱 Frente de Caixa (PDV)
- 📒 Caderneta de Fiado Digital
- 📦 Controle de Estoque
- 🏷️ Cadastro de Produtos
- 👥 Cadastro de Clientes
- 💬 Cobranças automáticas via WhatsApp
- 📊 Relatórios Financeiros
- 🎁 Programa de Fidelidade/Recompensas
- 💰 Pix, Boleto, Crédito e Débito
- 🔑 Gerador de Chave Pix por cliente

### 4. Seção de Planos
Dois cards de preço:
- **Plano Fiado** — R$ 89/mês: Caderneta de fiado digital, cobranças WhatsApp, relatórios básicos, cadastro de clientes
- **Plano Completo (PDV + Fiado)** — R$ 189/mês: Tudo do plano Fiado + Frente de caixa, estoque, produtos, fidelização, gestão financeira completa

Cada plano com botão "Assinar Agora" (por enquanto abre WhatsApp ou link)

### 5. Screenshots do Sistema
Carrossel/galeria mostrando as telas reais do sistema (usando as screenshots enviadas)

### 6. FAQ
Perguntas frequentes sobre o sistema

### 7. Footer
- Logo, links, contato WhatsApp
- "HappyCash - Sistema de Gestão 2.0"

## Design
- Tema escuro (dark mode) combinando com as screenshots do sistema
- Cores: amarelo/dourado (da logo), azul/cyan (da logo), fundo escuro
- Visual moderno e profissional
- Responsivo (mobile-first)
- Animações suaves ao scroll
